Lentelė rodo visą Lietuvą.

Kaip skaičiuojama
  • Duomenys: Via Lietuva atviras jungčių būsenų API (ev.vialietuva.lt), nuskaitomas kas ~3 min.
  • Užsistovėjimas: jungtis „Užimta“ ilgiau, nei lėtai kraunančiam automobiliui reikia 36 kWh (20→80 %) toje jungtyje, plius 15 min. Naktinės AC sesijos (pradžia 20:00–07:00) neskaičiuojamos.
  • Blokavimas: užsistovėjimo laikas, kai visoje stotelėje nebuvo nė vienos laisvos jungties.
  • Simuliatorius: atlaisvintas laikas = blokavimas po nemokamo laiko × laiku patraukusių dalis. Blokavimas laikomas tolygiai pasiskirsčiusiu per užsistovėjimą.
  • API neskiria „krauna“ nuo „baigė, bet stovi“, todėl tai įvertis pagal laiką. Su operatorių OCPP duomenimis jis būtų tikslus.
